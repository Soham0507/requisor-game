---
name: Imported game preview boundaries
description: Why imported game branding previews must remain distinct from live campaign services.
---

Treat full branding support and live campaign readiness as separate capabilities. Guest catalog demos must be explicitly labeled; never imply persistent scores, player accounts, or real leaderboards when those services are not connected.

**Why:** Jeopardy's import contained a usable frontend but not complete runnable backend sources. Enabling branding customization therefore used its existing game interface with an isolated guest demo, rather than exposing an unfinished login/admin flow or pretending server features worked.

**How to apply:** Preserve this separation when extending imported games. Live Jeopardy campaigns require a real, validated server-side question/result service and privacy-safe persistent leaderboards before removing demo labels.
